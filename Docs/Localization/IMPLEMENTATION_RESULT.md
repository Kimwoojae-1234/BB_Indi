# 영어 기준 로컬라이징 적용 결과

적용일: 2026-09-27 / 프로젝트: BB_Indi / Unity 6000.3.9f1

## 수정 기준과 결과

**고정 UI만 자동 로컬라이징한다. 코드가 텍스트를 제어하거나 외부 데이터가 채우는 필드에는 로컬라이즈 컴포넌트를 붙이지 않는다.** 코드에 작성된 고정 안내문은 기존 요청대로 영어 기준 번역을 유지하되, 코드가 필요한 시점에 조회해 대입한다.

- 해시형 키 1,190개를 의미 있는 키 1,168개로 바꿨다. 같은 의미이고 번역이 충돌하지 않는 22개 항목은 합쳤다. 예: `Common.Action.Confirm`, `Baseball.Stat.BattingAverage`, `Baseball.Result.HomeRun`.
- 사용하지 않는 샘플·임의 팀 이름 치환 항목 558개를 제거했다. `TXT_2DF81A77B973`는 로비 닉네임 샘플 `grigrigri`였으므로 새 이름을 붙이지 않고 삭제했다.
- 코드·데이터 소유 표시 위치 1,207개에서 자동 연결을 제외했다. 실제 제거한 `LocalizedText`는 968개이며 상속된 프리팹의 사용처에도 반영된다.
- 자동 연결은 고정 라벨 1,653개 위치에 남겼다. `LocalizedText` 1,568개 위치와 기존 `GameUILocalize` 85개 위치다. 비활성 UI도 포함한다.
- 런타임에서 컴포넌트를 추가하던 `LocalizedText.Set`을 제거했다. `L10n.SetText`는 한 번 대입만 하며 컴포넌트·언어 이벤트를 추가하지 않는다. 닉네임·서버 이름·점수·타이머·가격은 원래 컨트롤러가 계속 결정한다.
- `RttsTeam.Name`은 서버 값을 그대로 보존한다. 팀 인덱스에 따라 카탈로그 이름으로 치환하던 처리를 제거했다. 차트 계약에 명시된 번역 키는 기존처럼 코드에서 조회한다.
- 엑셀은 **2,640개 키**로 정리해 런타임 JSON으로 익스포트했다. 영어가 기준이며 기존 언어와 원문·사용처 열은 보존했다. 해시형 키가 새로 들어오면 익스포터가 오류를 내도록 했다.

전체 읽기 전용 UI 검사는 642개 프리팹·씬의 2,865개 텍스트 행을 검사했다. 연결된 텍스트 행 1,651개와 코드·데이터 소유 제외 1,207개 외에, 외부 예제 3개와 태그를 제외하면 수치인 4개가 있다. 고정 연결 검사에는 일반 문구 검사에서 걸러지는 2개 위치도 포함하므로 고정 연결 수는 1,653개다. 상세 목록은 `ui-audit-summary.json`과 `static-text-scope.json`을 참조한다.

Unity 배치 모드에서 변경 코드 컴파일과 검증 실행을 확인했다. 원본 자산을 일괄 저장하지 않고 검사했다. 기존 플러그인의 경고가 있어 전체 프로젝트가 경고 없이 빌드된다는 의미는 아니다.

## 운영과 보존

문구는 `Table/Localization_master_v2.xlsx`에서 수정하고 `Table/export_localization.py`로 익스포트한다. 적용 대상 판단과 코드 예시는 `Table/README.md`를 따른다. 새 UI 추가·경로 변경 시 `static-text-scope.json`도 갱신한다. 고정 UI를 코드 소유 텍스트로 바꾸면 바인더를 제거하고 제외 목록으로 옮긴다.

키 변경 이력은 `key-renames.json`에 있다. 이 이력의 옛 해시 이름은 런타임 별칭으로 사용하지 않는다. 최초 일괄 바인더 생성 도구는 폐기했으며 이전 계획·검증 기록은 `Library/Localization/HistoricalReports`에 보관했다. 이번 변경 전 백업은 `Library/Localization/CorrectionBackups`, 최초 이관 백업은 `Library/Localization/MinimalPatchBackups`에 있다. Library는 작업용이며 버전 관리 대상이 아니다.

원래 텍스트·레이아웃·이벤트·스크립트 참조를 보존하고 로컬라이즈 컴포넌트와 키 참조만 수정했다. 이전부터 있던 미커밋 작업은 유지했다.

## 검증 범위

- 전체 게임을 직접 플레이하며 화면별 잘림·배치를 확인하는 시각 검수는 수행하지 않았다. 이미지에 구워진 글자도 별도 작업이다.
- 영어 외 언어의 완역·폰트·줄바꿈 검수는 완료 범위에 포함하지 않는다.
- 기존 한국어 스킬 설명 35건은 영어와 인자 번호가 달라 엑셀 원문을 보존하고 JSON에서는 영어 대체를 사용한다. `export-warnings.txt`에 기록했다.
- 의도적으로 빈 설명 53개와 원본 중복 키 7행의 이관 기록은 보존했다. 사용자 입력·임의 서버 문구·로그·리소스 식별자를 번역 상수로 바꾸지 않는다.

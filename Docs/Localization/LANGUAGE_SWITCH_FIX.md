# 언어 변경 표시 수정

2026-09-27. BeachBaseball의 활성 목록과 동일한 영어·일본어·한국어·스페인어·중국어 번체(대만) 5개를 선택한다.

## 원인

언어 선택값과 PlayerPrefs 저장은 정상 작동했지만 로비와 설정에 사용하는 새 키의 번역 열이 비어 있어 영어 대체가 발생했다. 기존 검사는 선택값과 체크 표시만 확인해서 실제 화면 문구가 그대로인 문제를 놓쳤다. 설정창의 언어 버튼도 현재 언어가 아니라 고정 키 `UI.Label.English`를 표시했다. TMP 전역 대체 폰트가 비어 있어 한글·일본어·한자가 누락 글리프로 표시될 수 있었다.

## 수정

- 로비·설정·언어 선택창 및 같은 문구를 쓰는 공통 메뉴의 빈 번역 193칸을 채웠다. 기존 번역, 영어 원문, 키와 나머지 언어 열은 보존했다. 엑셀과 익스포트 JSON을 함께 갱신했다.
- `Popup_Setting`이 현재 언어의 현지어 이름과 국기를 표시한다. 이 텍스트의 자동 로컬라이즈 컴포넌트를 제거하고 해당 컨트롤러가 값을 관리한다.
- 이미 프로젝트에 있는 `NotoSansCJKkr-Black.otf`로 동적 TMP 대체 폰트를 만들고 TMP Settings에 등록했다. 기본 영문 폰트와 프리팹 글꼴 설정은 보존한다. 동적 아틀라스는 실행 중 필요한 글자를 추가하며 여러 아틀라스를 지원한다.
- 언어 검사에 로비·설정·언어 선택창의 실제 표시 문자열, 선택 언어 이름·국기, 글리프 지원 검사를 추가했다. 에디터 미리보기 객체에서 활성화 콜백과 클릭 이벤트를 실행한다. 사용자의 언어 설정은 검사 후 복원한다.

## 범위와 잔여 번역

선택할 수 있는 언어 목록과 전체 번역 완료 여부는 다르다. 영어는 기준 언어이며, 이번에 확인한 로비·설정·언어 선택창은 5개 언어의 번역을 갖춘다. 다른 화면에는 기존 미번역 항목이 남아 있어 영어로 대체된다. 빈 값을 영어로 복사해 번역 완료로 처리하지 않았다.

| 언어 | 검사한 화면의 빈 번역 | 전체 카탈로그의 빈 번역 |
|---|---:|---:|
| 영어 | 0 | 0 |
| 일본어 | 0 | 1,865 |
| 한국어 | 0 | 844 |
| 스페인어 | 0 | 1,807 |
| 중국어 번체 | 0 | 1,865 |

상세 키와 영어 원문은 `language-coverage.json`에 기록했다. 의도적인 빈 설명 53개는 누락 집계에서 제외한다. 한국어 집계에는 인자 불일치로 런타임에서 영어 대체하는 기존 35개도 포함한다.

전체 플레이 화면의 다국어 배치 검수와 나머지 화면의 완역은 수행하지 않았다. 코드가 채우는 선수 이름·닉네임·스탯 등에 자동 로컬라이즈 컴포넌트를 추가하지 않는다.

## 검증 결과

- 5개 언어의 실제 프리팹 문자열·선택 언어 이름·국기·글리프 검사 통과.
- 언어 저장·선택 표시·재열기·숨김 항목 거부·5개 버튼 배치 검사 통과.
- 고정 라벨 1,652개 및 코드/데이터 소유 텍스트 제외 1,208개 범위 검사 오류 0개.
- 로컬라이즈 동작 검사 21개와 Python 검사 14개 통과.
- 엑셀 수정은 번역 193칸 및 상태 85칸으로 제한되었고, 나머지 셀 보존과 JSON 일치를 확인했다.

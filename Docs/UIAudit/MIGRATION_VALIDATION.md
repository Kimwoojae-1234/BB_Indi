**최신 범위 변경: 현재 실제 사용하는 UI만 전환**

사용자가 실제 동작하지 않는 UI는 전환하지 않아도 된다고 명시했다. 따라서 미사용이 확인된 자산은 전환 대상과 진행률 분모에서 제외한다. 기본 비활성 상태이거나 검사 중 나타나지 않았다는 이유만으로 미사용으로 판정하지 않는다. 자동 진행·선수 교체·스킬·결과 등 조건부 실행 경로를 확인하고, 사용 여부가 불명확한 자산은 보류로 기록한다. 기존 자산 삭제나 현재 기능 제거는 이 범위 변경에 포함하지 않는다.

앞서 보고한 전체 2.7%, 메인 경기 프리팹 5.5%는 미사용 가능 자산을 포함한 직렬화 컴포넌트 감소율이다. 실제 사용하는 NGUI 전환 대상의 총량은 아직 확정되지 않았으므로 실사용 기준 전환율은 미산정이다. 이미 UGUI인 로비·새 결과 화면의 비율과 이번 NGUI 전환 작업의 진행률도 구분한다. [실사용 범위 확인 기록](RUNTIME_SCOPE.md)

현재 진행 순서는 스코어보드 표시 → 구종 선택 → 주루 → 일시정지/교체 → 경기 이벤트/연출이며, 실제 사용이 확인되는 선수 정보·Quick/PVP/결과 UI를 포함한다. 선수 정보는 `GIRL_PLAY`에서 숨기는 경로 외에 다시 활성화하는 경로도 있어 사용 여부 확인이 필요하다. Quick/PVP/레거시 결과를 자산이 존재한다는 이유만으로 일괄 전환하지 않는다. 관련 NGUI 의존성이 다른 기능에 걸쳐 있으면 필요한 연결을 포함하되, 각 변경 단위가 검증 가능한 크기를 유지한다. 실제 사용하는 UI를 숨겨서 전환 완료로 처리하지 않는다.

최종적으로 현재 사용하는 UI의 표시·입력·연출 및 이를 지원하는 공유 처리에서 NGUI 실행 의존을 제거하고 기존 게임 동작을 검증한다. 미사용으로 확인된 씬·프리팹·코드의 보관과 NGUI 플러그인 자체의 삭제는 완료 조건에서 제외한다. tk2d의 게임 렌더링까지 삭제 범위를 확대하지 않는다. 기존 버그는 기준선에 기록하고, 이전으로 새로 발생한 회귀는 해당 단계에서 해결한다.

확인 결과에는 대상 커밋/변경 파일, 플랫폼·해상도·게임 모드, 수행한 시나리오, 성공/실패/미검증, 로그와 화면 증거를 기록한다. NGUI 제거와 정상 동작 기준을 충족한 뒤 로컬라이징 작업으로 넘어간다.
